# ShopEase

**Course & Section:** BSIS 2B  
**Academic Year:** 2026–2027 (1st Semester)  

## 📌 Project Overview
**ShopEase** is a full-stack web-based platform designed to streamline campus buying, selling, and order management for students, professors, and administrators at Bicol University Polangui (BUP).

## 🎯 Key Features
* **User Authentication:** Secure registration and login for BUP students, professors, and admins.
* **Product Catalog & Search:** Browse, filter, and search available items.
* **Order Management:** Place orders, track order status, and view transaction history.
* **Admin Dashboard:** Manage product listings, user accounts, and system reports.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Version Control:** Git & GitHub
